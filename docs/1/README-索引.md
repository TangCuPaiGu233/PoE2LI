## 🚀 怎么跑代码

```bash
cd poe2_crawler/parsers
python3 ascendancy_parser.py
```

预期输出：8 职业 × 23 升华的归属表 + 10 个关系校验全部 PASS + 零噪声，
并生成 `poe2_ascendancy_graph.json`。

依赖：`requests` + `beautifulsoup4` + `lxml`（沙箱已装）。

## ✅ 已被真实数据验证的关键结论

1. **猎巫人 → 佣兵**（核心 bug 修复点）—— 实跑坐实，不会再推给女猎手。
2. PoE2 真实 **8 职业**（非 12），职业→升华唯一权威源是 `/cn/Ascendancy_class`。
3. 关系抽取必须靠 **DOM 结构块（figcaption）**，不能靠链接邻近顺序猜（否则 296 条脏边）。
4. **关系正确性 > 关系数量** —— 这是知识图谱质量的命门。
